# Doutrina Content

Repositório **exclusivamente de conteúdo** para os trabalhos de Allan Kardec.

### Estrutura
- `pdf/` → Arquivos-fonte originais (referência).
- `books/md/` → Versões derivadas em Markdown (editadas e estruturadas para consumo digital).

### Aviso de Direitos Autorais
Os textos originais de Allan Kardec são de domínio público.  
As traduções e edições aqui presentes (principalmente a de Guillon Ribeiro publicada pela FEB) são protegidas por direitos autorais.  

Este repositório é mantido **apenas para fins de estudo, pesquisa e desenvolvimento de edições digitais pessoais**.  
Não possui fins comerciais. Qualquer uso além do estudo pessoal deve respeitar os direitos dos detentores das edições consultadas.
